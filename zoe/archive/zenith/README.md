# ZENITH: AMD Creative Pathways Final Pitch

**Owner:** Zoe · *(Hillary's work goes in `/hillary/`, kept separate)*

We're reworking **"AMD Powers What's Next"**, a single 2-minute corporate brand video, into
**ZENITH**: an animated miniseries set in a futuristic city that runs on AMD, launched and kept
alive by short vertical sizzle reels and a creator competition.

> **One-line pitch:** Stop telling people AMD is everywhere. Build a city where they *find* it everywhere.
